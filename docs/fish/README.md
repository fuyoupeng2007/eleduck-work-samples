# 钓迹钓点与渔获日志

依据钓鱼类小程序需求制作的响应式 Web 个人样品。支持示意钓点筛选、收藏、渔获日志录入及编辑、鱼种和饵料记录、放流标记、统计与 CSV 导出。可备份恢复。钓点为虚构示意，未接真实地图，未发布微信小程序。

[在线体验](https://fuyoupeng2007.github.io/eleduck-work-samples/fish/) · [需求来源](https://eleduck.com/posts/lafmO1) · [全部作品](https://fuyoupeng2007.github.io/eleduck-work-samples/)

## 功能

示意钓点筛选、收藏、渔获日志、重量校验、放流登记、日志导出。

## 体验与验收

通过仓库根目录 `node serve.mjs` 启动，访问 `http://127.0.0.1:8770/fish/`。新六个工作台需要 HTTP 或 GitHub Pages，直接 file:// 打开无法加载 ES modules。

收藏到日志连续操作，渔获可编辑和导出，手机布局便于查看。

## 范围

没有 uni-app 包、地图 SDK、数据库、社交与微信登录；原岗位要求开发经验。

自主个人样品，使用虚构数据，AI 辅助开发；不代表雇主委托、仍在招人或已验收。
