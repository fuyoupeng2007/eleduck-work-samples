MASON METAL WordPress 安装说明

这是配套样品包，未在客户的 WordPress / Astra / Elementor Pro 实例运行。请先在客户的测试站安装检查，再决定实际部署。包内不含付费插件、授权码、客户数据或支付密钥。

路线 A：完整样品页面

  1. 在测试站安装并保留 Astra 父主题。
  2. 后台“外观 → 主题 → 添加主题 → 上传”，选择 mason-metal-child.zip，安装并启用子主题。
  3. 新建一个页面，页面模板选择“MASON METAL 完整样品”，发布后即可访问。
  4. 需要设为首页时，在“设置 → 阅读”中选择该页面。仅在确定测试站使用方式后修改。

这一路线完整复现本地样品，包括导航、主视觉、商品演示、购物袋、护理和咨询消息下载。页面模板不依赖 Elementor Pro，不自动修改数据库或创建商品。

路线 B：Elementor 模板

  1. 先安装 Astra 子主题，使短代码与资产生效；继续使用客户现有的 Elementor / Elementor Pro 授权。
  2. 在 Elementor 模板库中导入 MASON-METAL-Elementor首页.json。
  3. 新建 Elementor 页面，布局设为 Elementor Canvas，在页面中插入刚导入的模板。
  4. 标题、介绍和主按钮使用 Elementor 原生控件；系列、品牌介绍、护理、页脚和弹窗由子主题短代码加载。
  5. 图片通过子主题资产引用，不需要填写示例媒体 ID。若标题或主视觉需要进一步修改，在原生控件和主题 assets/design.css 中调整。

模板采用 Elementor 文档规定的 JSON 结构。不同客户版本的实验功能和容器设置可能影响导入结果，需在测试站核验。此次不声称其已通过真实 Elementor 导入验收。

V2 交互与素材

子主题已同步 3 张独立戒指概念图、商品搜索排序、收藏、最多 3 款对比、尺码参考与购物袋备注。收藏、购物袋和备注只保存在当前浏览器。图像为设计概念，不是客户真实商品摄影；尺寸参考也需按实物确认。

连接真实商品

主题包含可选的 [mason_metal_live_catalog] 短代码，安装 WooCommerce 后可以展示实际商品列表。演示系列使用的是 [mason_metal_collection]。正式接单时，需要把演示商品和购物袋替换为客户真实的 WooCommerce 商品、购物车和结账流程，并测试库存、变量尺码、物流与支付。

真实目录短代码不自动创建商品，也不配置收款。WooCommerce 商品页继续使用父主题的既有模板，尚未交付定制版单品页和结账页。

文件结构

  • style.css：Astra 子主题声明和基础扩展样式。
  • functions.php：资源加载、样品短代码和可选真实目录。
  • template-mason-metal.php：完整样品页面模板。
  • assets/：原创主视觉、页面样式和交互脚本。
  • partials/：首页与独立模块 HTML。

上线前的具体缺项

客户参考站及需复刻的页面清单、真实商品图与 SKU、品牌文案、材料与尺寸表、目标市场、币种、配送及退货规则、商户支付配置、现有插件版本。拿到这些后才可给出商业上线的验收结果。

实现依据

主题声明与加载方式参照 WordPress 子主题文档和 Astra 子主题说明；模板结构参照 Elementor JSON 通用结构。
